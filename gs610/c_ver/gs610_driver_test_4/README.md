# GS610 C 语言电流扫描程序

`gs610_sweep.c` 将同目录 `gs610_sweep.py` 的串口扫描逻辑移植到 C11，使用 Windows 原生串口 API，无需 Python、pySerial 或第三方串口库。原 Python 文件保留用于对照。

## 编译和运行

### 图形界面

编译后双击 **`gs610_gui.exe`**，或在 PowerShell 运行 `.\gs610_gui.exe`。界面使用原生 Windows C / Win32 与 GDI，无需 Python、Qt 或其他运行时；原命令行程序 `gs610_sweep.exe` 继续可用。

1. 点击“刷新串口”列出 COM 口及适配器名称。切换 COM 口自动发送 `*IDN?`，显示仪器返回的厂商、型号、序列号和固件信息；也可以点击“识别设备”重新查询。适配器名称与实际仪器名称分别显示。识别过程不配置扫描或开启输出。
2. 点击“高级设置”下方的串口参数按钮，选择波特率、数据位、校验位、停止位、流控、结束符和超时。设置仅作用于电脑端，需与仪器面板 `MISC → Remote I/F → RS232` 保持一致。修改后可重新识别设备。
3. 在设备参数区设置初始电流、截止电流、正步进、对称限压、每点等待时间，以及单程或往返扫描。目前设备配置为 GS610 / 765501 的恒流输出、电压测量，电流量程由全部扫描点自动选择。
4. 点击“运行”，后台执行设备识别、配置和采集。右侧横轴为实际经过时间（秒），纵轴为测得电压（伏），蓝色表示往程，橙色表示返程，同时显示最新电压、设定电流和采集进度。图表随数据自动缩放。
5. CSV 路径留空时自动生成到程序目录 `result`；也可浏览选择新文件。每点保存，拒绝覆盖已有文件。GUI 正常完成后关闭输出；点击“停止”或运行中关闭窗口时，先请求停止并尝试关闭输出，等待工作线程结束。通信中断时会提示在仪器面板确认输出状态。

勾选 **“演示模式（不连接仪器）”** 后运行，可使用模拟电阻负载产生的电压检查曲线和 CSV，无串口操作；演示数据在界面明确标注，自动文件名以 `demo-` 开头。取消勾选后才会采集真实仪器数据。

通信、CSV 保存和等待均在后台线程执行；采集期间锁定参数，停止按钮保持可用。真实扫描仍由 `gs610_sweep.c` 执行，通过逐点回调将记录交给 GUI；沿用原有定点电流计算、读回检查、限压验证、测量超量程检查和异常关闭输出逻辑。

### 命令行

在 Windows 安装 Visual Studio 2022 或 Build Tools 的“使用 C++ 的桌面开发”组件，运行：

```powershell
.\build.bat
.\gs610_sweep.exe
```

不带参数运行时逐项交互设置；回车接受默认值。默认起始电流为 **-3.2 A**、截止 **+3.2 A**、步进 **0.08 A**、限压 **12 V**、每点等待 **0.1 秒**，默认双程。实际连接前请根据被测对象设置参数。

也支持 CMake（Windows）：

```powershell
cmake -S . -B build/cmake
cmake --build build/cmake --config Release
```

查看串口和设备型号：

```powershell
.\gs610_sweep.exe --list
.\gs610_sweep.exe --port COM4 --identify
```

`--list` 不打开串口；`--identify` 仅发送 `*IDN?`，不配置扫描或改变输出。请将示例中的 COM4 换成实际串口。

先预览，再执行扫描：

```powershell
.\gs610_sweep.exe --dry-run --round-trip --start -0.01 --stop 0.01 --step 0.001 --voltage-limit 5
.\gs610_sweep.exe --port COM4 --round-trip --start -0.01 --stop 0.01 --step 0.001 --voltage-limit 5 --dwell 0.1
```

`--single-pass` 选择单程；未指定扫描方向模式时会询问。步进必须为正数，电流升降方向由起止值决定。`--keep-output` 仅在所有扫描点及数据保存成功后保持最终电流输出；双程的最终电流为初始电流。

串口默认 `9600 / 8N1 / 无流控 / LF`。仪器面板设置必须匹配：

```powershell
.\gs610_sweep.exe --port COM4 --baudrate 9600 --bytesize 8 --parity N --stopbits 1 --flow none --terminator LF --timeout 5 --round-trip
```

支持波特率 `9600/14400/19200/38400/57600/115200`、数据位 `7/8`、校验 `N/E/O`、停止位 `1/2`、流控 `none/xon/rtscts` 和结束符 `CR/LF/CRLF`。完整选项见 `--help`。适配器驱动见原项目的“串口驱动-使用前安装”目录。

## 与 Python 版本一致的扫描行为

1. 校验有限数字、电流范围、量程分辨率、最大扫描点数和限压。
2. 选择能够覆盖全部电流点的最小固定量程。±3.2 A 使用 3 A 量程，此时最大负载电压为 12 V。
3. 往程和返程均包含完整起止点，转折点独立测量两次；最后一步不足步进时补入精确终点。
4. 根据 `*IDN?` 的型号字段确认设备为 `765501` 或 `GS610`。
5. 进入远程模式、关闭输出，设置直流电流源、立即触发、对称限压和电压测量。逐条检查设备错误，读回限压及测量模式。
6. 每点设置并精确读回电流；第一点才开启输出并确认状态。等待 `dwell` 后，用 `:READ?` 发起新测量，检查设备错误和超量程状态。
7. 每完成一点立即保存 CSV。默认在结束时关闭输出；异常和 Ctrl+C 时也会尝试关闭输出。

查询必须收到完整结束符，最大响应缓冲区为 4096 字节，读取超时按整条响应计算。超时、残缺或非 ASCII 响应会使会话失步，之后停止查询，防止迟到响应被误认为下一条查询的结果。失步后仍发送 `:OUTP OFF`，但无法确认设备状态时会明确提示。Ctrl+C 退出码为 130，其他失败为 1，成功为 0。

## CSV 文件

默认保存到 exe 所在目录的 `result` 子目录，文件名使用 UTC+8 日期时间及进程号。相对路径相对于 exe 所在目录解析，支持中文路径。指定路径的父目录需已存在。

```powershell
.\gs610_sweep.exe --port COM4 --single-pass --start 0 --stop 0.01 --step 0.001 --voltage-limit 5 --csv result/my-test.csv
```

文件使用带 BOM 的 UTF-8 和 CRLF 换行，便于 Excel 读取。单程列为：

```text
point,elapsed_s,set_current_A,measured_voltage_V
```

命令行采集电压和 CSV 的 `measured_voltage_V`（含返程列）统一四舍五入到小数点后四位，并补足末尾零；CSV 的 `elapsed_s` 也保留四位小数。设定电流保持量程要求的精度，避免小电流被截为零。交互设置中的时间默认值以简洁形式显示，例如 `0.1`，不显示二进制浮点尾数；这些显示格式不会改变内部等待和扫描计算精度。

双程在右侧增加 `return_point,return_elapsed_s,return_set_current_A,return_measured_voltage_V`。往程与返程按各自的采集顺序逐行配对，因此同一行不一定具有相同设定电流。返程的 `point` 继续往程编号，`elapsed_s` 从整个扫描开始计时。

输出文件在扫描配置前独占创建，已有文件不会覆盖。往程逐点追加，返程先写同目录临时快照，再替换 CSV；返程替换失败时保留上一份完整结果。无法保证断电或强制终止进程时关闭仪器输出。

## 手册依据与实现边界

已阅读 `info/IM765501-01E.pdf`，核对内容包括：

| 手册章节 | C 版本实现依据 |
| --- | --- |
| 14.1–14.5 | RS-232、波特率、数据格式、流控及结束符 |
| 16.2 | `SOURce`、`SENSe`、`TRIGger`、`OUTPut`、`SYSTem` 命令 |
| 16.2.11 | `:READ?` 启动新测量并读取结果 |
| 16.3 | `:STAT:SENS:COND?` 第 5 位 OVR 表示测量超量程 |
| 18.1 | 各电流量程的输出能力、分辨率和最大负载电压 |

当前版本面向 **Windows**，未实现 Linux/macOS 串口后端。电流参数使用 `int64_t` 的 100 pA 定点数，接受十进制与科学计数法，避免浮点步进误差；有非零数位低于 100 pA 的输入会拒绝。与 Python 的任意精度 Decimal 相比，C 版步进参数另受 `int64_t` 表示范围约束（约 9.22×10⁸ A），远高于仪器允许的输出电流。时间、限压和采集电压使用双精度数。
