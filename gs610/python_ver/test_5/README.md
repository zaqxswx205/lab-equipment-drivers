# GS610 test5：Python 图形界面版

基于 test4 增加图形界面，供已安装 Python 的电脑运行。test4 未修改。

## 安装与启动

建议 Python 3.8 或更高版本，需包含 Tkinter。在本目录打开终端：

    python -m pip install -r requirements.txt
    python gs610_gui.py

Anaconda 用户请先在终端激活环境，再运行以上命令。“串口”必须填写 COM3、COM4 等，不能填 Anaconda 的 activate 文件路径、Python 路径或环境名。

如果缺少 Tkinter，请为所用 Python 环境安装 Tk 支持。串口适配器仍需在 Windows 中正确安装驱动，本目录不附带驱动安装包。

## 使用

1. 连接设备，点击“刷新串口”并填写实际 COM 口。点击“串口设置”可调整波特率、数据位、校验位、停止位、流控、结束符和超时，点击“确定”保存；通信参数须与设备一致。
2. 设置初始电流、截止电流、正数步进电流、限压、每点采样前等待时间（默认 1 秒）及往返模式。单位为 A、V、s。默认沿用 test4：-3.2 A 到 3.2 A 再返回，步进 0.08 A，限压 12 V。请按被测样品调整后开始。
3. 选择新的 CSV 文件名，点击“开始采集”。每得到一条读数，立即更新电压大字显示、设定电流、进度、时间曲线和记录表。曲线时间包含通信及等待耗时，实际采样间隔不严格等于等待时间。
4. “停止并关闭输出”会请求停止。等待期间可立即响应；串口通信期间需等待当前操作返回或超时。采集中关闭窗口会先请求停止、关闭输出，再退出。

界面在正常结束、停止和异常时均尝试关闭输出，不提供完成后保持输出选项。通信故障时无法保证关闭成功，请在仪器面板确认并关闭输出。

## 无设备演示

勾选“模拟演示”后开始，不会连接真实设备。模拟电压按电流乘 2 欧姆生成，并限制在设置的限压范围内。界面标记为模拟数据，自动文件名带 demo- 前缀；自选文件名按原样使用。演示仍写入 CSV，请勿将模拟数据当作实测数据。

## Linear 仪器扫描

软件使用仪器内置 Linear 扫描：设置 `:SOUR:MODE SWE`、`:SOUR:CURR:SWE:SPAC LIN` 及 STAR/STOP/STEP 参数，读回确认后开启输出。起止电流之差必须为步进的整数倍。

使用 INT 内部定时触发（`:TRIG:SOUR TIM`）。每程发送一次 `:SWE:TRIG`，仪器自动推进电流并存储测量结果，不再逐点发送 `:INIT`、`*TRG` 或 `:FETC?`。电脑轮询 `:TRAC:ACT?`，按缓存编号读取电流、电压及相对时间，串口读取滞后不会跳过缓存中的点。每程最多 65535 点。

“采样前等待”对应输出改变后的测量延时 `:SENS:DEL`；`S.Delay`（触发到输出改变的延时）设为最小值。内部触发周期自动设为等待时间加 0.3 秒，预留测量和量程切换时间。例如等待 1 秒时，自动步进周期为 1.3 秒。等待时间范围为 0–3599.7 秒；0 使用仪器最小测量延时（1 微秒）。若仪器报告触发过快的 Sampling error，程序停止并提示。

去程和回程分别配置并启动一次，转折点各测一次；两程之间短暂关闭输出，因此转折点不保证电流连续。显示和 CSV 每读到一条缓存记录就更新。相对时间使用仪器缓存时间加每程在电脑上的启动偏移。

命令依据：官方手册第 16-22 至 16-26、16-29 至 16-30、16-46 页。已通过模拟测试，仍需实机验证自动扫描、缓存和测量结果。+300 硬件输入异常仍按故障停止；切换 INT 不代表此错误已排除。

## 默认 4W 四线制接法

程序每次扫描均在输出关闭时发送 :SENS:RSEN ON，并用 :SENS:RSEN? 确认返回 1；未成功切换会报错停止，不开启输出。图形界面与命令行扫描均默认使用 4W。

- OUTPUT Hi、OUTPUT Lo：分别连接样品两端，提供扫描电流。
- SENSE Hi、SENSE Lo：另外用两根线分别连接样品对应的 Hi、Lo 两端，测量样品端电压。SENSE 线应接到样品测量位置，不能悬空。

不要仅连接 OUTPUT 两根线就使用此默认设置。4W 的 SENSE 接线断开会导致感测错误。

官方依据：GS610 用户手册 IM765501-01E 第 4.2 节与第 16-25 页：
https://cdn.tmi.yokogawa.com/1/6104/files/IM765501-01E.pdf

## 数据保存

默认保存在本目录自动创建的 result 文件夹，自动文件名包含北京时间时间戳，每次开始生成新文件名，不覆盖已有文件。每点先保存到 CSV，再更新界面；停止或出错时保留已保存数据。

沿用 test4 格式：单程为点号、时间、设定电流和电压；往返时去程与返程分别在左右两组列中，按各自采集顺序配对，转折点测量两次。表格显示最近 500 点，CSV 保留全部。曲线点数过多时按屏幕宽度显示各段极值。

## 文件

- gs610_gui.py：图形界面、后台采集及模拟演示。
- gs610_sweep.py：采集逻辑，增加逐点回调、停止请求与串口名校验，仍可命令行运行。
- requirements.txt：唯一第三方运行依赖 pyserial。
- tests：扫描、保存、停止与串口校验测试源码。

不包含 exe、打包工具、内置 Python、虚拟环境、离线依赖或驱动安装包。运行 Python 时可能自动生成 __pycache__ 缓存。

可选验证命令：

    python gs610_sweep.py --list
    python gs610_sweep.py --dry-run --single-pass --start 0 --stop 0.002 --step 0.001
    python -m unittest discover -s tests -v

已通过 12 项自动测试（包含 4W 设置失败时阻止开启输出）和窗口模拟验证，覆盖实时读数、曲线、记录表、往返 CSV、停止、重新开始和采集中关闭窗口。真实仪器通信需连接 GS610 后验证。
