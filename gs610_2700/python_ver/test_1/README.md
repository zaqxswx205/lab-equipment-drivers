# 610 电流输出 + 2700 前面板电压采集

## 图形界面

驱动设备内部测量延迟设为最小值，INT周期独立设为界面的输出保持时间；采集设备的中点读取延迟不再占用驱动设备内部测量周期。

允许起止差值不是步长整数倍：例如 -0.5→0.5 A、步长0.08 A，生成 -0.5、-0.42、…、0.46、0.5 A，共14点。
等步长部分使用Linear/INT扫描，剩余截止点单独启动一段；段间关闭再开启输出，因此末点边界存在通信配置间隙。
返程反向经过相同电流点，每点保持时间和中点采样规则不变。该处理不依赖设备对不足一步的隐式取整方式。

点击“扫描串口设备”可预读所有可用串口的 `*IDN?` 身份，列表显示串口、设备用途、原始身份和通信参数。
扫描仅发送身份查询，不配置输出。按两个设备当前高级设置中的通信参数尝试识别；若参数不匹配，先调整高级设置后重扫。
唯一匹配的采集设备和驱动设备自动填入串口框；多台同类设备请手动选择。测试与扫描互斥。

“数据记录地址”默认指向程序目录的 result 文件夹，可点击“选择保存位置…”选择CSV文件路径，也可直接编辑路径。
已有文件不会覆盖；再次开始测试会在上次选择的目录中生成新的时间戳文件名。

默认起始电流 -3.2 A、截止电流 3.2 A、步长 0.08 A（80 mA）、限压12 V。
界面仅设置每点输出保持时间（默认2秒）；采样延迟自动取保持时间的一半（默认1秒），以只读文字显示。
中点采样是稳态读数的时序安排，不代表已满足任意信号带宽下的采样定理；保持时间仍需容纳2700积分和串口读数时间。
数据记录始终保留，逐条刷新落盘。图形界面CSV列为 timestamp、direction、point、set_current_A、drive_voltage_V、voltage_V；timestamp记录采集设备读取完成时的年月日和时分秒（YYYY-MM-DD HH:MM:SS，例如2026-11-04 15:30:31），日期与时间之间为空格，不含毫秒。
历史表依次显示驱动电流（设定值）、驱动电压、采集电压。drive_voltage_V通过FETCh读取驱动设备最新的内部电压读数（面板M值），不额外发起测量，也不按缓存点号读取；voltage_V来自采集设备的中点读数。两者依次查询，并非硬件同步；驱动电流仍是软件计划的设定值。周期过短时程序会停止并提示增大保持时间。

直接运行 `python main.py` 或 `python gui.py` 打开界面。
界面支持两台设备串口选择、各自的高级设置按钮、返程测试勾选、实时读数表格及去程/返程 I–V 曲线。
点击开始前安装 requirements.txt 中的依赖。

图形界面使用610 Linear扫描，INT内部触发周期由每点保持时间决定，扫描末点保持至本程结束。
2700 NPLC=1，默认在电脑发送扫描触发后的第1、3、5…秒开始读取；调整时间参数后相应改变。
这是软件定时近似：发送触发的时刻不等于仪器实际电流改变时刻，尚无硬件同步保证。
调度延迟超过0.2秒或读取完成跨越下一点时停止测试。
每程结束检查610缓存点数及采样错误。返程单独启动一程，转折点重复测量。
每点一次的稳定电压读数不用于证明满足任意输入波形的奈奎斯特采样要求。
请在实机上验证输出切换时刻与测量窗口，当前仅通过界面创建及语法检查。

以下命令行模式仍保留原先的逐点软件设置方式；Linear/INT固定时序通过图形界面使用。

两套原驱动已复制到本目录，原目录不作修改。运行时不依赖原目录。
采用电脑逐点设置电流、等待稳定、读取2700的顺序，非硬件同步扫描。

接线：610 OUTPUT 接被测负载两端；2700 前面板 INPUT HI/LO 并联负载两端，注意极性。
2700 FRONT/REAR 实体开关置 F。610 使用本地感测（2W）。
两台仪器串口默认 9600、8N1、无流控；610 默认 LF；2700 发命令使用 CR。

安装依赖：`python -m pip install -r requirements.txt`

扫描示例（请按实际串口及负载允许值修改）：

```powershell
python main.py --port2700 COM3 --port610 COM4 --start 0 --stop 0.01 --step 0.001 --voltage-limit 1 --settle 1
```

恒流采集100次：

```powershell
python main.py --port2700 COM3 --port610 COM4 --start 0.001 --stop 0.001 --voltage-limit 1 --samples 100 --interval 1
```

加 `--dry-run` 只检查参数，不连接设备。加 `--round-trip` 往返扫描。
`--help` 查看量程、积分时间、波特率和流控选项。
CSV 默认保存在本目录 result 下，逐条刷新落盘，不覆盖已有文件。
CSV 电流为设定值，电压来自2700；不是610实测电流。
正常完成、异常和 Ctrl+C 都尝试关闭610输出；通信失败时需按终端提示在面板确认。
采样间隔是读数完成后的等待时间，实际周期还包含通信和积分时间。
