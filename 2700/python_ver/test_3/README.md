# Keithley 2700 逐通道独立测量项目（test_3）

在 test_2 基础上独立建立，支持 7702 / 7700 以及原前面板模式。每个模块通道可以使用不同的测量功能、量程、NPLC 和切换稳定时间。test_1、test_2 不依赖本项目，也无需修改。

默认示例已经启用：**101 测两线电阻，102 测直流电压**。默认模块是 7702，两通道均自动量程、NPLC=1、稳定时间=0.5 秒。

## 启动

Python 3.10 或以上，包含 tkinter。运行：

```powershell
python -m pip install -r requirements.txt
python main.py
```

也可以双击本目录的 `启动程序.bat`，务必关闭旧版程序再启动本项目，避免串口被占用。

## 配置 101 电阻、102 电压

1. 在“连接与前面板参数”页设置串口、波特率、超时、FLOW 和每轮间隔。模块模式下，本页的功能/量程/NPLC 仅供前面板模式使用，模块实际参数由逐通道配置决定。
2. 切到“逐通道配置与保存目录”页，输入来源选择 7702（或实际使用的 7700），将仪器 FRONT/REAR 输入开关切至 R。
3. 表格中选中 **101** 行，在编辑区选择“两线电阻 Ω2”，输入量程 `AUTO` 或基本单位 Ω 数值，设置 NPLC 和稳定时间，点击 **“应用并启用选中通道”**。
4. 选中 **102** 行，功能选择“直流电压 DCV”，例如量程 `10` V、NPLC `0.1`、稳定时间 `0.5` 秒，再点击应用。
5. 根据实际需要配置其他通道，或选中后点击“禁用选中通道”。表格中“✓”表示已启用，“—”表示不采集。可使用 Ctrl / Shift 多选后批量应用相同参数。滚动表格可查看槽位2的 201 等通道。
6. 选择保存目录，点击“测试连接”，确认两个槽位型号；再点击“连接并开始采集”。如果卡位于槽位2，请禁用默认的 101/102，改为配置 201/202 等通道。

编辑区参数修改后须点击应用；未应用的编辑会阻止开始采集。切换选中行会加载那一行已应用的配置，未应用的编辑不保留。采集期间配置被冻结，停止后可修改。配置在本次程序运行中保留，关闭程序后不自动保存配置，下次启动恢复默认示例。

电阻通道接无外部电源的被测电阻；电压通道接电压信号。切换测量功能会改变仪器激励方式，应按各通道实际接线设置功能。物理输入开关不能由软件代替操作。

## 每个通道的参数

| 参数 | 含义 |
| --- | --- |
| 功能 | DCV、ACV、DCI、ACI、两线电阻、四线电阻 |
| 量程 | AUTO 或正数，以 V / A / Ω 基本单位输入；实际可用档位由仪器检查 |
| NPLC | 0.01–10，积分周期数 |
| 稳定时间 | 0–60秒，切换连接到该通道后额外等待的时间 |

每轮间隔、串口、通信超时、保存目录属于整次采集的公共设置。所有启用通道按照编号升序依次测量；一轮耗时超过目标间隔时不补发积压读数。因此混合功能采集不是同时采样，也不是硬件定时采样。

交流测量沿用 test_2 的 300 Hz 检波带宽设置，使 NPLC 指令有效，当前不提供 3/30 Hz 带宽选项。未增加温度、频率等功能。

## 模块通道限制

| 模块 | 电压/两线电阻 | 四线电阻主通道 | 电流通道 |
| --- | --- | --- | --- |
| 7702 | 每槽 CH01–40 | CH01–20，感测通道为主通道+20 | CH41、42 |
| 7700 | 每槽 CH01–20 | CH01–10，感测通道为主通道+10 | CH21、22 |

101 表示槽位1 CH01，201 表示槽位2 CH01。一次可使用一张或两张同型号模块，当前不混用一张 7700 和一张 7702。内部继电器不能作为测量通道选择。

**四线感测通道不能同时配置为其他测量输入。** 例如 7702 的 101 设置四线电阻后，121 被占用；若同时启用 121 测电压，程序会阻止开始并说明冲突。101 四线电阻与 102 电压则可一起配置，前提是接线符合实际用途。

切换模块型号时，超出范围的通道自动禁用；不再合法的测量功能恢复为该通道可用的默认功能，并取消启用，需要重新确认和应用。

## 实时显示与数据保存

- 实时表格同时显示各通道的功能、读数、单位、状态、更新时间和累计点数。左侧通道颜色对应曲线。
- 曲线按电阻 Ω、电压 V、电流 A 分页，避免不同量纲共用数值轴；切换曲线页不影响其余通道采集。各通道曲线最多保留最近 2000 点。
- 每点先写入 TXT，并执行 flush / fsync，然后更新界面；TXT 保留全部数据。OVERLOAD 时记录状态、数值留空，曲线断开。
- TXT → CSV 支持 test_3、test_2 及旧版前面板 TXT。CSV 为带 BOM 的 UTF-8，不覆盖已有文件。

TXT 是 UTF-8 制表符分隔文本，字段为：

```text
timestamp channel mode unit value status
```

其中 timestamp 为电脑收到读数后的本地时间，精确到毫秒。TXT 和 CSV 仅保存上述六列，不保存 raw、source、range_setting、nplc_setting、settle_s。旧格式 TXT 仍可转换，导出时移除多余列；旧前面板文件补 channel=FRONT。历史 TXT 原文件保持原样。模拟模式仍在界面显示，并使用 SIM 文件名前缀区分。

## 指令与故障处理

沿用 test_2 的 RS-232 8N1、固定 CR 发送、自动识别接收结束符、错误队列、通道号核对和通信日志。新项目的日志、默认数据目录均位于 test_3 内部。

开始时执行一次复位，关闭内部扫描与自动通道配置，设置单次触发和 READ/CHAN 数据格式。每个通道读取前：

1. 检查实体输入开关。
2. `ROUT:OPEN:ALL` 断开输入，避免带着前一通道连接切换测量功能。
3. 用全局 `SENS:FUNC` 选择目标功能，再设置其自动/固定量程、交流带宽（如适用）及 NPLC。
4. `ROUT:CLOS (@通道号)` 选择系统通道，主机自动处理四线配对及背板继电器。
5. 等待该通道稳定时间，通过 `READ?` 触发新数据并核对返回通道号。

每条参数指令通过 `*OPC?` 和错误队列核验。连续通道参数完全相同时复用已确认参数，仍逐通道断开/连接并等待稳定。发生错误或取消时执行清理，打开通道、恢复本地操作并释放串口。

## 验证范围

```powershell
python -m unittest -v
```

32项自动测试通过，包括原前面板与模块功能，以及混合六种功能、同功能不同量程/NPLC、自动量程恢复、参数错误时禁止接通、四线感测冲突、混合单位模拟数据、精简字段保存和历史数据转换。另已验证 Tkinter 界面中编辑/应用 101 电阻与 102 电压、混合采集、单位分页曲线、导出、模块切换和前面板模式重启。

未连接真实仪器验证新功能。首次使用建议用已知电阻和已知电压核对 101/102 的功能、读数及保存文件，再增加通道。
